# 对话示例（mes_example）写作模板

mes_example 教模型"这张卡的戏怎么演"：节奏、台词密度、描写比例、格式习惯。

## 格式

```text
<START>
{{user}}: 一句用户输入
{{char}}: 角色的回应（含动作描写与台词）
{{user}}: 下一句
{{char}}: 下一段回应
```

## 写法建议

- 给 **2-3 组**完整往返即可；组与组之间展示**不同情绪状态**（平静 / 冲突 / 亲密），而不是同一种语气的重复。
- 示例里的描写比例就是模型会模仿的比例：想要少描写多对话，示例就先做到。
- 示例中不要出现世界观专有名词的解释性长段（那是世界书的活）。
- 角色犯错、停顿、嘴硬的样例比完美回答更能立住人设。

## 检查项

- [ ] 使用 `<START>` 分隔每组。
- [ ] {{user}} 与 {{char}} 占位符拼写正确（写错会导致示例失效）。
- [ ] 示例语气与 description 的说话方式一致。
