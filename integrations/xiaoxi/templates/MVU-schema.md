# MVU 变量设计检查单

MVU = 卡内持久变量系统：schema 定义结构，初始化写入初值，更新规则让模型在每轮产出变更，运行时回写并在状态栏/提示词中投影。

## 字段准入（每个字段都要过）

- [ ] **有消费者**：这个字段会被状态栏、正则、世界书条件或剧情逻辑读取吗？没人读就不要建。
- [ ] **有写入者**：初始化或更新规则里谁写它？两者都没有＝死字段。
- [ ] **类型最小**：能用数字不用字符串，能用枚举不用自由文本。
- [ ] **默认值明确**：初始化失败时系统应回落到的值。

## 生命周期追踪表（写 schema 前先填）

```text
字段 -> 初始化来源 -> 更新规则编号 -> 模型投影格式 -> 读取方 -> 清理/迁移策略
```

## 更新规则写法

- 一条规则只改一类字段；规则之间不互相覆盖同一字段。
- 规则里写清触发条件（剧情事件）与变更幅度（+1 / 设为 X / 追加条目）。
- 输出格式与 schema 严格一致；给一个正例一个反例。
- 区分"剧情模型负责叙事"与"更新模型/更新段负责变量"，两者职责不混写。

## 检查项

- [ ] schema 与更新规则的输出格式逐字段对齐。
- [ ] 没有任何字段缺少消费者或写入者。
- [ ] 初始化不依赖开场白之外的隐藏事件。
