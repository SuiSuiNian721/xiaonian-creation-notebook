# 角色描述（description）写作模板

description 是模型每轮都会看到的"角色本体"。写事实和约束，不写说明书。

## 结构建议（按需取舍，不必全写）

1. **身份一句话**：是谁、在做什么、和 {{user}} 的默认关系。
2. **外貌与气场**：只写会被观察到的特征（3-6 条），避免堆形容词。
3. **性格与说话方式**：
   - 性格用"会怎么做"写，不用标签堆砌（"被质疑时先沉默两秒再反问" 优于 "傲娇"）。
   - 说话方式给 1-2 个可直接模仿的特征：句长、口头禅、忌讳的词。
4. **行为边界**：角色绝不会做的事、不知道的事。边界比特质更能稳住人设。
5. **与 {{user}} 的关系张力**：默认立场 + 可能变化的方向，给互动留坡度。

## 检查项

- [ ] 全文用第三人称或设定口吻，不混入对模型的下指令口吻（指令放 system_prompt）。
- [ ] 没有把世界书内容复制进来（世界书放 worldbook/，靠触发词按需注入）。
- [ ] 没有写"你是一个 AI"类出戏内容，除非设定本身需要。
- [ ] 长度克制：能删的句子就删，模型可见文本越精越稳。
