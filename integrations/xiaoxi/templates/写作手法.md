# 角色写法手法速查

写 description / 世界书人物条目时可用的几种组织手法，按角色类型挑一种主轴，别混用成杂烩。

| 手法 | 适合 | 做法 |
| --- | --- | --- |
| 三面性 | 有秘密或反差的角色 | 分"外人看到的 / 亲近者看到的 / 只有自己知道的"三层写，层间留矛盾点 |
| 性格色板 | 情绪驱动型角色 | 定 3-4 种主情绪，每种给触发条件 + 外在表现 + 台词样例 |
| 多阶段 | 会成长/堕落的角色 | 按剧情阶段写状态快照，注明阶段切换条件（配合世界书或 MVU） |
| 功能位 | NPC / 工具人 | 只写职责、知道什么、不知道什么、会给什么阻力；不写内心戏 |
| 关系网 | 群像卡中的角色 | 以"对每个关键人物的立场"为主轴写，性格藏在立场差异里 |
| 改写立人 | 有原作底子的二创 | 先摘原作事实，再写本作偏离点与偏离原因，偏离处必须显式标注 |

## 通用纪律

- 一种手法做主轴，其他手法最多补一条。
- 每条设定问一句"模型在哪一轮会用到它"；用不到的删掉或挪去世界书。
- 反差和边界比优点更能让角色活：至少写一条"绝不会做"和一条"嘴上不说但会做"。
