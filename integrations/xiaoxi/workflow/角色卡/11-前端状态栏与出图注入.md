# 模块 11 · 前端状态栏与出图注入（角色卡 · 按需）
> 概括：按需。回复末尾的变量面板（状态栏），以及把标签换成图/视频的注入正则；显示与提示词成对，取数带 stat_data 前缀。

共用技术口径见 `workflow/MVU共用规范.md`；变量定义、计算职责、回流、显示与验收按该规范执行。

## 何时进入
10 之后。这张卡要**变量面板**，或要在聊天里**出图 / 出视频**时才做；纯文字卡跳过。要显示变量的，先有 06 的变量结构。

## 状态栏：三条路选一
1. **MVU 占位符 + 成对正则**（`mvu.mjs` 给骨架）：MVU 自动在回复末加占位符，一条 `promptOnly` 正则抹掉、一条显示端换成 HTML 面板。模型不手写。
2. **整段 HTML 状态栏**：一条显示端正则把占位符或标签换成完整 HTML 文档。自由度高、体积大。
3. **EJS `@@iframe`**（见 12）：模板渲染时读取变量，适合静态面板；需要实时订阅时用酒馆助手前端。

## 出图 / 注入：把标签换成媒体
- 模型按世界书输出格式吐标签（如 `<pic>场景名</pic>`），显示端正则用**捕获组**把它换成媒体：`/<pic>(.*?)<\/pic>/gi` → `<img src="图床/$1.webp">`；视频同理 `<video>`。
- 捕获组可用于媒体路径或正文，按渲染环境处理编码与转义；14 的同层 UI 同样适用。
- 提示词端仅移除无剧情语义的媒体控制信息；若标签是唯一的场景说明，保留可读描述。
- 图床用 https 直链；路径里中文/空格要编码。

## 硬规矩（写错就整块坏）
- 状态栏 HTML：脚本先 `await waitGlobalInitialized('Mvu')`，再按所在楼层用 `Mvu.getMvuData({type:'message', message_id:getCurrentMessageId()})` 取值；从 `stat_data` 读取字段，变量更新事件后重渲染。边距放在面板容器上。
- 成对正则**别配反**：显示端只管显示，`promptOnly` 只管抹回传。
- 正则勾"AI 输出、编辑时运行、仅格式显示"。

## 产出落点
- 正则脚本与面板 HTML：`src/extra.json` 的 `extensions.regex_scripts`（`mvu.mjs gen … --card` 会先写入 MVU 那 5 条，本步在其上追加）。
- 用 EJS 路线的状态栏条目：`src/worldbook/`。

## 助手怎么做
1. 先和用户定三条路选哪条、要不要出图。
2. 给正则 + HTML 骨架落进 extra.json；样式与取数字段由用户调。
3. 跑 `node tools/diagnose.mjs <卡>` 看「正则脚本」「运行时接线」「角色脚本」，再按硬规矩自查一遍。
4. 明说面板观感与真机生效**只能用户验收**。

## 从玩家视角检查显示

状态栏只挑玩家行动前真要知道的量。例如角色是否疲惫、当前位置和一项与当前抉择有关的关系；把整个 `stat_data` 原样铺开，通常只会遮住对话。用户若想在钟楼场景显示插图，先确认该场景确实有素材、标签何时出现、无图时正文是否仍可读。图片资源的缓存和变量保存各有职责，不能互相代替。

取一段短消息、一段长消息以及图片加载失败的情况，检查面板是否压住正文、正则是否把唯一的剧情描述删掉。角色卡的界面风格应由角色和作品气质决定，助手只给可运行骨架和检查依据，不照搬参考卡外观。

## 引导与确认流程

1. 先用大白话说明本模块要解决什么、结束时会得到什么，不从工具命令或术语开始。
2. 读取已有 `src/` 与已确认计划，跳过用户已经回答的内容；每轮最多追问两三个与当前缺口直接相关的问题。
3. 用户卡住时给 2–3 个方向，并说明各自会怎样影响体验；示例必须标明是启发，不得自动进入正式内容。
4. 动手前在对话中展示完整待确认稿：正文或结构、目标文件、世界书条目与侧车配置、脚本/正则改动及外部依赖。明确列出仍属待定、不写入的内容。
5. 只有用户明确确认当前稿可以写入后才修改 `src/`。涉及世界书时同时遵守 `workflow/世界书写入指南.md`；用户要求调整时先改草稿并重新确认受影响部分。
6. 写入后按 UTF-8 回读，运行本模块规定的检查，汇报实际文件和未验证项；未确认、未写入或检查失败时不得标记完成或推进 stage。
## 完成标准
按选型验收：占位符方案检查显示/提示词正则，原生 EJS 方案检查模板取值；剧情语义保留，diagnose 无 error，已告知需真机验收。

## 红线
**不执行卡内 HTML/EJS/脚本，只读分析 + 生成文本**；不写酒馆安装目录；不抄参考卡界面与文案（只取公开语法事实）；真机验收权留给用户。
