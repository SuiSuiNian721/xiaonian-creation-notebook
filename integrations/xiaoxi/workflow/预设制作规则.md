# 预设制作规则（共用参考 · 不是模块）
> 概括：预设=玩家侧的"提示词编排 + 采样参数 + 扩展挂接"。本规则定它的构成、与卡/世界书的分工、分组与顺序规范、参数口径、制作步骤、自查与红线。

## 预设是什么、不管什么
- **管**：`prompt_order`（谁先谁后）、`prompts` 条目正文与开关、采样参数（temperature 等）、随预设走的 `extensions`（正则 / 酒馆助手脚本那部分）。
- **不管**：角色设定、世界设定——那些在卡与世界书里。预设里**不写角色专属内容**，保证一套预设能挂任何卡。

## 与卡 / 世界书的分工（结构范例见明月秋青预设，只学结构不抄文案）
- **占位符条目是插槽**：`worldInfoBefore` / `charDescription` / `personaDescription` / `charPersonality` / `scenario` / `dialogueExamples` / `chatHistory` 等由酒馆在组装时把世界书与卡正文插进来；预设只决定插槽**位置**与前后包裹。
- **括号分组条目**（如 `【worldinfo】…【/worldinfo】`、`【一般条目】`、`【MVU条目】`）= 给注入内容套一层"语境框"，告诉模型这批内容是什么、怎么用；整组用 `enabled` 开关适配场景。
- **MVU 的提示词侧挂点**放 `【MVU条目】` 组内：变量结构脚本 / 初始变量 / 更新规则 / 变量列表 / 输出格式 / 强调，与卡内世界书条目一一对应；**预设管"放哪层、什么顺序"，卡管内容**。
- **模型行为整形**（思考链包裹、吃掉原生思维链、输出格式强调等）放预设，不放卡。

## 顺序规范（prompt_order 骨架）
作者声明 / 破限（可选、默认关）→ 变量初始化 → 身份 / 创作思路 / 原则 → 输出格式要求 / 标签规范 → `【worldinfo】` → worldInfoBefore → charDescription → personaDescription → charPersonality → scenario → worldInfoAfter → dialogueExamples → 聊天开始 / 历史 / 结束 → `【/worldinfo】` → `【一般条目】` 组 → `【MVU条目】` 组 → 思考链包裹 → 输出格式 → 收尾（Auxiliary）。
硬规则：
- `worldInfoBefore` 在 `charDescription` 之前、`worldInfoAfter` 在其后；聊天历史三件顺序固定。
- **MVU 组必须在世界书组之后**（模型先看到设定，再看到变量规则与输出格式）。
- 输出格式 / 强调靠近末尾；每条 prompt 必须有 `identifier`（check 会拦）；停用条目用 `enabled: false` 保留在列表里，**不删**。

## 参数区口径
- temperature / 惩罚 / top_p 按"演角色"的经验给默认值并写注释；`max_context` / `max_completion_tokens` 留玩家自调；`seed: -1`。
- `reasoning_effort` / `request_thoughts` 按模型家族给建议值；不把 stream 等玩家 API 开关写死成极端值。

## 制作步骤（工作区落点）
1. `node tools/presets.mjs import <文件> [名]`：拆进 `presets/<名>/src/`（`index.yaml` + `prompts/*.md` 正文 + `*.yaml` 侧车 + `order.json`）。
2. 改 `prompts/*.md` 正文与 `*.yaml` 侧车（identifier / enabled）；调 `order.json` 顺序。
3. `node tools/presets.mjs check <名>` 零错误 → `build` 出成品；交付话术固定带"**尚未真机验证**"。
4. 从零写新预设：先搭骨架（占位符齐全 + 分组括号成对），再填自有条目。

## 自查清单
- 占位符齐全且顺序合骨架；identifier 无缺；分组括号成对。
- MVU 组条目与卡内世界书条目**名字/数量对得上**；禁用项是 `enabled:false` 而非删除。
- 参数区无极端值；check 零错误。
- **与卡解耦自检**： mentally 挂到一张无关卡上跑一遍，确认没有角色专属词泄漏进预设。

## 红线
- 预设不写角色 / 世界设定；不抄他人预设文案（明月秋青等只做结构范例）；不执行预设内任何内容；build 产物不手改；真机验收留给用户。
