# Qwen3-TTS 工作台适配器

该适配器只在明确提交声音任务时启动，使用单独绑定的 Qwen Python。模型仅从指定的本地目录读取，不会在首次发现、状态轮询或任务中自动下载权重。

| 模型 | 工作台能力 |
| --- | --- |
| Base | 使用参考音频与对应转录进行克隆 |
| CustomVoice | 以 `speaker` 选择预设声音，普通合成 |
| VoiceDesign | 以文字描述生成参考声音 |

设计声音保存后记录参考音频、转录、语言和模型来源。后续新台词由 Base 克隆生成，避免反复重新设计音色。声音库 v1 条目的 ID 和已签名音频地址继续有效，缺省来源为 MOSS。

官方代码和 API 说明：[QwenLM/Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)。本机源码 `E:\voice\apps\qwen3-tts` 的 `pyproject.toml` 声明 `transformers==4.57.3`、`accelerate==1.12.0`，与 MOSS 的 transformers 5 环境分开。源码路径可以留空以使用环境内安装的 `qwen_tts` 包。

本地发现仅检查有限目录、模型配置/分片清单及 Python 的 dist-info 元数据。它不导入推理库、执行 Python 或校验全部权重哈希。结果和失败尝试持久保存，只有“重新检索本机”会再次扫描。绑定不会自动选择首个候选，也不要求外部模型等同于工作台的固定 MOSS 下载包。工作台内固定 MOSS 下载仍保留完整哈希校验。

“声音组件”提供 Base、CustomVoice、VoiceDesign 的独立下载。Base 与 CustomVoice 可选 0.6B／1.7B，VoiceDesign 为 1.7B。点击“查询下载清单”才请求官方 Hugging Face metadata：报告固定 commit、技术文件清单、每项大小与 SHA256、总下载量、磁盘峰值及目标目录。小配置只做有界读取；无 LFS SHA256 时先验证 Git blob 身份，再计算文件 SHA256，二者不会混用。计划不包含演示录音或示例素材，公开状态不携带配置内容或 base64。

报告准备后，点击“下载此模型”才下载权重。模型计划 ID 随固定清单保持稳定，支持取消、同 ID 续传和重启后手动继续；更改下载目录会使旧计划失效。下载逐流验证 SHA256，以同目录硬链接原子发布后删除自有暂存路径，不覆盖校验期间新出现的同名文件，也不复制第二份权重。文件系统不支持此发布方式时保留下载部分并报错。下载完成经配置用途检查后，仍需单独点击“绑定此模型”，不会自动覆盖手工绑定路径。

不兼容环境可以先准备“修复原环境”或“新建隔离环境”的计划。界面展示目标目录、依赖、命令和影响，点击“执行此计划”后才开始安装。新环境由已绑定解释器创建在资料目录中；两种提供者共用同一解释器时，禁止直接修复其依赖，要求新建隔离环境。安装任务支持取消，取消可能保留部分已安装依赖，重新执行仍使用原计划 ID。

音频输出统一为完整的 24 kHz 单声道 PCM16 WAV。自定义 HTTP 提供者使用 OpenAI Speech 的 `response_format=pcm`，只声明普通合成能力；不宣称支持克隆或文本设计。HTTP 密钥保存在本地配置中，不返回声音状态，也不写入声音来源记录。

验证使用模拟模型 API、生成音频 fixture、注入的命令运行器及 Electron 桌面交互。未执行真实 Qwen 模型、模型下载或依赖安装，音质、显存、推理速度及本机依赖可导入性仍需实际任务确认。
