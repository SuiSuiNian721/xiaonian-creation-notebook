# AI 接入

工作台设置保存全局默认连接。每个模块右上角都有一个小「AI 接入」按钮，点开浮层修改，关闭后继续原来的工作。

默认「跟随全局」。选择「自定义部分字段」后，只填写想改变的项目，空字段继续继承全局。例如，全局模型是 A，在绘图模块只填模型 B，地址、密钥与思考档位仍跟随全局。全局以后修改的值会更新到未覆盖的字段。

| 字段 | 模块空值／默认选择 |
| --- | --- |
| 接入方式、模型、API 地址、思考档位 | 继承全局对应字段 |
| 启用 AI | 跟随全局，也可单独启用或停用 |
| API 密钥 | 跟随全局；也可单独填写，或明确不使用密钥 |

专属密钥留空保留已保存值；切回全局密钥后不再使用该专属密钥，仍保留以便以后切换。模块地址不同且仍使用全局密钥时，浮层会明确显示「此地址将使用全局 API 密钥」。密钥不会回传页面或写入公开日志。

「当前生效」显示已保存配置。未保存的修改不会用于测试；测试会真正等待模型回复，并显示经过时间。测试期间可以继续输入，新的草稿会保留，完成后才能保存或再次测试。连接失败不会改用另一套模型或服务。

切回「跟随全局」保留已保存的模块覆盖；未提交的覆盖草稿也保留在当前会话中。关闭浮层或按 Esc 会收起；离开模块后再次打开仍恢复当前会话草稿。尚未保存的 AI 设置草稿不保证跨应用重启保留。保存只改本机配置，不自动发送推理、加入游戏、生成图片或启动训练。

九个模块共用这一入口与配置规则。当前真正调用该 AI 接口的业务是角色卡助手、绘图工作流助手、MC 皮肤设计和 MC 陪玩；其余模块可预先配置，业务能力仍以模块页面为准。ComfyUI 模型与生成参数继续在绘图工作流中设置。

绘图 MCP 的开关、服务地址与令牌仍由工作台全局管理，不随模型接入来源切换。MCP 对外供其他 AI 调用 ComfyUI，与这里选择文本／视觉模型的用途不同。

## Codex 桥接

内部模型调用先通过 CLI 的 `config/read` 读取当前 MCP 名称，再在本次生成子进程中禁用这些额外工具。不改写用户的 Codex 全局配置，也不降低模型或思考档位。技能、图片与结构化输出仍由原输入通道传递；CLI 自带服务可能仍启动。

此优化避免无关工具的启动超时拖住测试连接。本机对比使用相同已安装 CLI、`gpt-6.1-sol` 和 `xhigh`；速度仍会受网络、服务状态和模型响应影响。真实验收证据见对应验证记录。
