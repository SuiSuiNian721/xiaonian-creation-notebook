# 训练参数与输出

## 一键训练

选择底模和训练图集后，可以直接选择「输出目录」。每个流程在所选目录下建立独立文件夹，流程记录展示实际位置；暂停、重试和工作台重启沿用同一位置。留空时优先使用训练设置中的输出位置，否则使用受管流程目录。原始训练图集不会被移动或覆盖。

「仅处理图集」也使用所选输出位置保存图片与标注副本。该模式留空时使用工作台流程目录。

「显存选项」提供当前引擎支持的梯度累积、梯度检查点及相关 CPU 卸载选项。留空或选择「跟随参数方案」时使用默认／AI 建议；显式设置的值优先，AI 不会替换它。独立 MOSS 原版没有梯度累积或图集重复次数，不显示无效控制。

一键流程按原生引擎映射参数和图集：Kohya 使用 TOML 子集；Musubi 建立单独的重复次数子目录副本；MOSS 使用自己的预缓存；DiffSynth、AI Toolkit 和 Anima Fast 使用各自的数据字段。Edit 配对图集应在「全量调整训练」中配置。非 Kohya／Musubi 的一键流程暂不支持原图与裁切图分别设置重复次数，应使用默认整图模式。

## 全量参数

表单直接读取本机 Next Trainer 对应的 20 份活动训练 schema，覆盖六个引擎。可搜索参数名，简要说明通过信息按钮打开，支持键盘焦点和点击。参考图目录可逐项选择，预览样例可分别编辑提示词、尺寸、种子和采样参数。

训练时长遵循原生定义：AI Toolkit 用步数；DiffSynth 用轮数；Anima Fast 使用自身模式；独立 MOSS 支持轮数与步数上限；Musubi 同时填写时按原生步数优先；Kohya 保留轮数／步数二选一。

切换训练类型时清理旧引擎已知但新引擎不支持的参数，保留未知高级配置。预设和 JSON 原样保留分支草稿；提交时仅去除已知但未激活的分支。完整 JSON 继续支持原版高级字段。

Flux 全量微调是内核兼容入口，原版没有独立参数表，界面明确标为「Flux 全量微调 · JSON」。

## 打标

「打标来源」默认使用本地模型，本地图集处理可独立使用。标签格式可选择 Next Trainer 的全部 10 个原生模型，在折叠参数中设置阈值、标签处理、递归、下载源及已有标签冲突策略；自然语言格式继续使用 Florence-2。工作流默认递归且保留匹配标注，参数可以调整。开启下载前只复用本地模型。

本地区始终显示「打标器」。默认自动匹配底模常用格式，并显示实际推荐名称；也可手动选择 Florence-2 或 10 个标签模型，手动选择优先。已发现的完整本地文件直接复用。「下载打标器」只准备当前选择的固定模型资产，不启动训练内核、打标或推理；支持状态、取消和失败重试。已指定的模型位置优先，未指定时可复用发现的 Florence-2 路径。

选择「接入 AI」时，图片工作副本会逐张发送给训练模块当前接入的视觉模型。预设跟随角色／画风／姿势用途，并可追加提示词；完整规则可以展开查看。图片与标注逐项校验、保存，同一流程重试会从已验证的进度继续。支持有效 PNG、JPEG、WebP，单图不超过 8 MiB；其他格式或大小应选择本地打标。

角色预设参考已有小璃身份绑定规则；画风和姿势是研究预设，尚未进行对应训练效果验收。规则、来源和取舍见 [标注预设研究](audits/2026-11-10-training-caption-rules.md)。

## 导出与运行边界

桌面导出统一使用系统另存为窗口，可选择目录和文件名。取消不产生导出文件；成功后，本次工作台会话记住保存位置。声音候选、已保存音色的参考音频和合成结果都提供「另存音频」。

参数可配置不代表对应引擎已安装；安装状态、原生预检与模型要求仍然生效。工程回归和模拟提交不能替代真实 GPU 训练、显存占用与输出质量验收。
