# 提示与资源准备

本轮沿用已有模块与资料目录，修正失效指路、保存和导出范围，并将缺依赖的位置连接到现有下载器或具体准备操作。

## 操作入口

- 角色文件分为图片、声音、MC 皮肤、角色模型、工作流和其他文件；添加前可从 info 查看格式及每文件 32 MiB 上限。模块顶部统一称「角色文件」。
- 「另存人设到角色资料」创建独立副本，不更新原资料。JSON 导出仅含人设、原始字段和文件索引，不包含文件本体、独立记忆或状态；这些范围在导出入口可查看。
- 实例栏「陪伴模式」控制文字／形象陪伴；人设窗口「角色功能」控制基本记忆／完整状态规则。关闭标签继续后台运行，停止由实例管理完成。
- 工作流检查显示缺失文件、实际值和允许范围。「准备模型／插件」带着缺项进入当前选中的启动器实例；普通返回保留尚未导入的 JSON 和检查结果。
- 子目录文件按基础文件名预填，显示原路径；下载后需在工作流重新选择或放回对应子目录。不能可靠确定来源时不猜下载地址或插件仓库。
- 绘图的清晰预览和启动器均可获取预览解码器。明确选择 SD1.5/SD2、SDXL、SD3 或 FLUX.1 后才填入对应官方 decoder；主动点击「开始下载」才进入已有下载队列，保存类别为 `vae_approx`。

## 环境准备

ComfyUI、训练、MC 皮肤配置页在路径表单上方提供准备入口，完整陪伴失败页提供兼容运行端获取与原生目录选择。官方来源在系统浏览器打开；更改本机路径后仍须保存、检查或明确启动。

| 对象 | 实际准备范围 |
| --- | --- |
| ComfyUI | 官方 Windows 便携包及其 Python，本地本体目录选择 |
| 训练 | 兼容 Next Trainer 根目录、服务 Python、Kohya 和标注依赖；原训练器负责其环境安装和修复 |
| 训练模型 | 底模及同一底模的配套组件由用户选择来源；下载开关仅负责标注／裁切权重 |
| MC 皮肤 | Python 3.10+、Pillow；可复制针对所选解释器的 PowerShell 安装命令，工作台不自动执行 |
| 完整陪伴 | 固定兼容 AIRI 0.12.0-beta.5；内置 JSON 规则初始化不包含运行端、角色模型或语音模型 |
| MC 陪玩 | 随桌面包提供的运行库完整性；缺少组件时说明需要修复完整桌面组件，不把下载游戏当作修复 |

上述新增入口不是新的自动环境安装器。已有声音、QQ、千问视觉安装器，以及训练处理权重、ComfyUI 模型和插件下载继续使用。模型和插件操作作用于选中的本机 ComfyUI，远端服务不会因此自动修复。

## 排错

全局 AI 的「本机 Codex 检查」仅读取 CLI 位置、版本与 ChatGPT 登录状态，不发送生成请求；可获取官方 CLI 或复制针对该 CLI 的登录命令。修改 AI 接入后明确要求先保存再测试。

声音克隆的「测试音色服务配置 → 测试声音服务日志」可读取最近启动日志，每个文件最多显示末尾 16 KiB，屏蔽凭据模式，不读取用户任意路径。新生成／克隆任务仍使用其任务状态和错误反馈。

## 验证

- 全量 Node 测试（并发 4）：1017 项，1004 通过、13 跳过、0 失败；跳过项需要显式真实 Python／进程环境或文件链接权限。
- 新测试覆盖缺项转义、下载预填、一次消费、原生选择与取消、陪伴恢复表单、CLI 状态、日志边界和外链处理。真实 Electron 回归验证待导入工作流经过资源准备后仍可继续检查。
- 隔离桌面资料中验证了两个启动器实例的跳转、深浅主题和 125% 桌面缩放；没有执行真实模型下载、环境安装、训练、QQ 登录或游戏连接。
- 训练源内的预检文案修改已同步完整性清单和内核版本标识。
