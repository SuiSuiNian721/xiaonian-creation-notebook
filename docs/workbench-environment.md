# 本机环境自动查找

进入 QQ、ComfyUI、角色绘图、MC 陪玩、训练工具或 MC 皮肤的配置区，会自动查找一次。选择候选后填入原表单，再点击原来的保存或连接操作；扫描不改已有配置。返回页面复用本次工作台的结果，点击「重新扫描」更新。

ComfyUI 识别本体或便携包中的本体，保留已填写的作品与工作流目录。训练工具识别已有安装，MC 皮肤可选择已有 Python；程序路径存在仍需原来的环境检查。

扫描提示直接标出 NapCat QQ 独立运行端、ComfyUI 本体、Next Trainer、Python 或 Minecraft Java 版局域网世界。扫描未找到只代表本次范围内未发现；已识别的不完整目录列出缺少的文件，权限和超时另作未核实提示。运行检查区分 Python 与 Pillow，MC 陪玩会列出缺少的 AIRI、tsx、isolated-vm 或 Node.js 组件。资源安装页和路径检查也显示具体对象名称。

QQ 只允许采用工作台固定版本的组件目录，保存前重新校验文件。组件可复用，账号、登录数据和令牌继续使用当前工作台的独立槽位。其他 NapCat 组件不能直接当作已验证的运行包；没有组件时从「准备 QQ 环境」安装。

MC 陪玩会接收 Java 版的局域网世界公告，填入来源地址和游戏端口。先在游戏中「对局域网开放」，再扫描；远程服务器仍可直接填写地址。发现世界不自动加入，也不能说明该世界的模组协议一定兼容。公告格式参考上游实现的 [LAN Announcer 协议说明](https://github.com/meh-is/LANAnnouncer#technical-details)。

文件扫描有时间、深度、目录和候选数量上限，优先已有配置、常见安装位置与本地固定盘上的软件目录，跳过链接、账号、大模型、依赖、缓存和备份。没有找到时可点「选择目录查找」，使用桌面文件夹选择器缩小范围，无需手输目录。

目前为 `feat/qq-roleplay-design` 分支上的源码功能，正式 EXE 尚未重新构建。软件只做桌面端；QQ 的手机扫码确认保持原流程。
