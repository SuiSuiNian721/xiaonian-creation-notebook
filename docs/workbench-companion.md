# 虚拟陪伴 · 使用与来源

工作台 0.10.1 的虚拟陪伴模块只读接入本机 AIRI 0.12.0-beta.5。后台沿用其主进程、原生服务和渲染能力；工作台重做了陪伴入口与设置首页，并适配具体配置页面的字体、配色和文案。具体配置控件仍复用原生实现，并非全部自行重写。

本分支的「打开 虚拟陪伴预览.cmd」启动独立预览资料。首次只读借用正式工作台已有的 AI 连接和主题，原有 AIRI 的资料保持独立；后续启动保留预览中的编辑。

预览的标准输出、错误输出直接保存在 `artifacts/companion-preview-profile/logs/preview-*-stdout.log` 和 `preview-*-stderr.log`，不会依赖启动终端保持运行。主进程在加载陪伴组件前处理标准输出的 `EPIPE` 断管事件，其他错误仍正常上报。

平台展示统一使用「AI-未来」「虚拟陪伴」和工作台图标。兼容层覆盖原生语言包、菜单、窗口标题和首次配置；内部协议标识、实际文件路径和第三方来源记录保留原样。角色卡与聊天内容不会被持久化改写。

## 使用

添加「虚拟陪伴」后打开模块。陪伴、聊天和设置在工作台内容区切换。右上角「AI 接入」沿用工作台的全局/模块连接。

- 「陪伴」只显示导入的个人模型。没有模型时显示导入入口，也可以先聊天；Hiyori、AvatarSample 等示例不会被选择、列出或加载。
- 「聊天」保留原生会话能力并使用平台配色。默认对话服务来源为工作台，支持 Codex 和 OpenAI 兼容服务。
- 「设置」先显示角色模型、声音和语音输入；其他配置收进「更多设置」。具体子页沿用适配后的原生控件。原生记忆管理仍未开放，入口为禁用状态。
- 「桌面陪伴」在已有个人模型时把舞台移到原生悬浮窗口。点击「陪伴」可收回。
- 「记录」显示工作台侧的启动和 AI 连接事件。
- 「沉浸模式」隐藏工作台侧栏、顶栏和外层页签，主体扩展到窗口。角色卡编辑器也有同一入口。F11 切换窗口全屏；Esc 同时退出全屏和沉浸，回到当前模块。进入、退出都不会重载编辑器或聊天。

首次接入使用独立的数据，原有 AIRI 的聊天、模型选择和服务密钥不会自动导入。角色模型从「设置 → 角色模型」导入和选择；等待念念提供模型期间保留空舞台。预留的旧 `modelPath` / `serviceUrl` 配置继续保留，实际模型选择使用上述入口，公共模型连接使用「AI 接入」。

## 角色与 AI

工作台选择的角色映射为 AIRI 原生角色卡，使用上游按 `activeCardId` 隔离的会话机制。切换前取消工作台模型请求并更新旧会话代次；新角色不会继承旧角色的历史。初始化时切换角色同样会校准到最后选择。

角色的名称、简介、性格、场景、系统提示与开场白会转成原生字段；模型、声音等原生扩展设置保留。未选择工作台角色时，可使用 AIRI 自己的角色卡。通过原生界面另选卡片后，公共 AI 桥按实际原生卡片判断身份，避免强加另一个工作台角色。

OpenAI 请求保留多模态、工具与事件流。Codex 通过已有桥接调用，支持结构化工具响应和最多四张本地图片；完成后转换为 AIRI 兼容事件流，不是逐 token 透传。远程图片 URL 或其他多模态类型需使用相应的 OpenAI 兼容服务。

语音合成、识别使用各自的服务，需要在陪伴设置中另外配置。独立「角色声音」模块仍保持原来的开发范围。

## 安装与数据

默认检测 `E:\AI-未来\AIRI`，也可使用 `AI_FUTURE_AIRI_PATH` 或模块的 `airiPath` 配置。没有安装时，错误页可保存安装目录。当前只兼容已核对结构的 0.12.0-beta.5；不匹配时明确拒绝加载。

当前工作台 profile 的 `data/companion` 保存新资料：

- `native`：原生配置、插件、MCP 与日志。
- `browser`：隔离浏览器会话、聊天和模型资料。

主程序通过限定来源的加载钩子适配 Electron app、session、菜单、快捷键和窗口，不覆盖原安装的 ASAR。通道使用独立端口和令牌；真实外部 AI 密钥留在工作台后端，原生界面只获得此实例的内部模型令牌。

随包保留 AIRI 的 MIT 声明。本候选包依赖现有本机安装，不把其完整资源、SDK 或模型重新打包。模型和 SDK 仍按各自授权使用。

## 生命周期与边界

离开模块隐藏嵌入视图并保留会话。移除入口会隐藏陪伴界面并取消工作台模型请求，资料保留。关闭整个工作台时，等待原生生命周期、插件宿主和其他服务清理。

在 AIRI 原生托盘中选择退出，仅结束陪伴运行端；当前版本需要关闭并重新打开工作台才能再次初始化完整引擎。界面会显示实际停止状态。修改安装目录也应重新打开工作台。

原生游戏页面保留上游行为；工作台现有 MC 陪玩继续使用独立的 0.15.1 运行端，两者没有自动合并会话或登录态。

真实声音、摄像头/屏幕、第三方 MCP、插件、Godot 和真实游戏世界需要分别配置验收。页面可达与完整代码接入不表示外部服务已配置或其效果已验证。
