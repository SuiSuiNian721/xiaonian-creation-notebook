# ComfyUI 实时日志窗口

桌面版 v0.8.2 提供独立日志窗口，参考绘世启动器的控制台使用方式。

在 ComfyUI 启动器点击“启动 ComfyUI”后，会自动弹出日志窗口。后台等到 ComfyUI 的服务状态和节点定义读取成功，再自动打开系统浏览器。同一次启动只自动打开一次；停止服务、更换配置或退出工作台会取消尚未完成的等待。五分钟仍未就绪会显示错误，也可在启动器手动点击“打开 ComfyUI”。

启动页右侧“启动日志”中的“独立日志”可以随时重开窗口。应用插件、更新、依赖安装或恢复计划后，会打开该管理任务的独立日志；历史管理任务也保留入口。安装仍遵循预览与应用流程，此窗口不会增加自动安装操作。

窗口支持选择文本、复制全部、保存为 UTF-8 日志和跟随输出。向上滚动会暂停跟随。关闭日志窗口只结束查看，不停止 ComfyUI 或取消安装；停止服务使用启动器原有的“停止”按钮。

## 实现边界

- ComfyUI 的标准输出和错误输出直接写入原有 `drawing/comfy-startup.log`，查看窗口读取最近 128 KiB。Python 采用无缓冲 UTF-8 输出。
- 管理进程通过 UTF-8 流回调持续追加任务日志，保留最近 32000 字符；发生截断时查看页会提示。
- 查看页每秒读取一次；选择日志文本时暂缓更新，避免破坏选区。浏览器模式可通过链接手动打开日志页。
- 只允许当前工作台的日志页写入系统剪贴板，其他权限继续拒绝。网页不具有 Node 或任意命令执行能力。
- 自动打开浏览器期间，握手前后都核对当前配置与原启动进程，防止旧启动结果打开过期服务地址。
