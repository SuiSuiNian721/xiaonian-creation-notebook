# 统一工作台视觉约定

参考来源为已保存的 Auroraqua-UI 原项目截图与材质。旧 Aurora Demo 保留原样，新界面位于 `public-workbench`。

## 结构

固定侧栏、顶部角色选择、中央工作区、按需打开的运行信息抽屉。首页展示模块入口与最近使用，模块目录提供分类、检索和添加。模块功能页保持统一外壳；业务内容按需扩展。

浅色使用温白、桃粉与淡紫背景，深色使用深蓝与蓝灰表面。玻璃面板保留边缘高光、偏移阴影和背景透色，按钮与图标尺寸一致。文字采用 Windows 可用字体，深蓝正文与明确字号层次承担结构。

## 文案与可访问性

执行念念新增的全局 UI 规则：不使用口号、欢迎段落或逐区块帮助说明。模块目录只展示图标、名称、info 提示与添加或打开按钮，不显示名称下方的工具小标签；工具名称仍可用于检索。业务状态在相应功能页呈现，补充说明放入 info 提示或折叠说明。

info 支持悬停、焦点、点击固定、Escape 和外部点击关闭。浮层有 `role=tooltip`，触发器提供可访问名称和展开状态。表单始终保留可见标签。角色简介属于用户内容，按原内容呈现。

ComfyUI 启动器按念念本轮要求，每项启动设置下方常驻一句效果和代价，参考绘世的呈现方式。标签、选项优先说明用途；技术缩写和版本限制放入 info，效果说明用 `aria-describedby` 关联控件。此约定针对启动设置，不扩展为所有页面的常驻帮助段落。

角色卡模块不展示“当前角色”侧栏及顶部角色选择器。后续写卡界面围绕作品的新建和编辑设计，不以全局选用角色作为创作前提；完整创作编辑器目前尚未接入。

移除模块是可恢复操作，按钮旁明确显示“保留配置与资料”。未来若增加不可逆删除，应把后果直接呈现在操作界面，不藏入 info。

验收尺寸包含正常桌面、125% 缩放和 390px 宽度。禁用、忙碌、错误、空数据和模块加载失败均需要可操作的恢复入口。减少动态效果时关闭动画与过渡。
