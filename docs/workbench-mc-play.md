# MC 陪玩

MC 陪玩在统一工作台内使用 AIRI Minecraft 运行端。添加模块后，在同一窗口打开“MC 陪玩”。

## 连接

1. 打开 Minecraft Java 版世界。单机世界可以通过“对局域网开放”提供连接端口。
2. 填写服务器地址和游戏端口。同一台电脑通常填写 `127.0.0.1`，端口使用游戏中实际显示的值。
3. 游戏版本默认自动识别，也可手动填写，例如 `1.21.1`。
4. 选择离线/局域网或微软账号登录。离线机器人名使用 1–16 位英文、数字或下划线，并与真人玩家不同。微软模式按连接时提供的设备码完成登录，需要可进入相应服务器的游戏账号。
5. 填写“你的游戏名”，让 AIRI 识别主人和跟随目标。
6. 点击“连接世界”。保存配置、打开页面或重启工作台都不会自动进服。

微软账号缓存只写入对应实例的 `data/instances/<实例 ID>/mc-play/auth`，不复制已有 AIRI 或 Minecraft 登录资料。认证页面固定由桌面宿主打开微软登录地址。

## 多个 Bot

在 MC 陪玩上方点击“新建实例”，每个实例对应一个 Bot。各自保存人设、连接、登录缓存、皮肤、指令与记录；“管理实例”可重命名、停止或归档。关闭标签后 Bot 仍在后台运行，需要退出世界时点击“断开世界”或停止实例。

同一世界中的 Bot 必须使用不同游戏身份。工作台在开始连接时预留名称，微软登录解析出真实名称和 UUID 后再次检查；重复身份会在进服前被阻止，运行端完全退出才释放占用。常见回环地址与 IPv6 等价写法共享检查，任意 DNS 别名是否指向同一服务器不作推断。

同服工作台 Bot 的聊天仍显示在记录中，但默认不触发彼此的 AI，也不能用聊天暂停另一 Bot。真人聊天及工作台内的显式指令继续有效。每个 Bot 仍需独立配置“你的游戏名”。

## Bot 皮肤

1. 打开对应 Bot 的“皮肤”页，导入 64×64 或旧版 64×32 PNG。选择 Steve／Alex 体型；旧版仅支持 Steve。导入只在本地保存，可查看正背面预览。
2. 连接世界，点击“上传并应用”。首次会把该 PNG 发送到 MineSkin，生成 Minecraft 标准签名纹理。当前支持匿名生成；遇到服务限额或认证错误时可稍后重试，或展开可选的 API Key 设置。Key 仅保存在当前实例，不返回页面。
3. 世界端安装兼容的 SkinRestorer，Bot 对自己发送换肤命令。只有运行端收到与当前选择一致的服务器玩家资料，界面才显示“世界已同步这套皮肤”。上传成功或命令发送成功不代表已经应用。

应用成功的皮肤在下次连接后自动核对。更换 PNG 或体型后需要重新点击应用；断开世界会取消当前上传与等待，旧结果不能影响新连接。“恢复默认”使用 `/skin clear`，恢复游戏缺省皮肤、关闭自动应用，已导入 PNG 保留。此操作不等于重新获取同名微软账号的皮肤。

### Fabric 1.20.1 局域网世界

开世界的一侧安装 [SkinRestorer 2.11.1+1.20-fabric](https://modrinth.com/mod/skinrestorer/version/ycz7WffZ)，要求 Java 17、Fabric Loader ≥0.15.0。把兼容 JAR 放入该版本实际使用的 `mods` 目录，重启 Minecraft 后再“对局域网开放”。其他玩家通过标准服务端纹理同步看见皮肤，不要求每个人安装这个模组；世界端的网络和换肤权限必须可用。默认允许普通玩家修改自己的皮肤，无需给 Bot OP。

若客户端装有 CustomSkinLoader，建议来源顺序为 `GameProfile` 在 `LocalSkin` 之前，避免同名本地图片遮住服务器的新皮肤。本地文件可保留作为没有服务器纹理时的后备。

## 陪玩

“跟随我”和“来到身边”调用 AIRI 原有动作工具。目标必须在机器人的可见玩家列表中。

自然语言指令使用工作台设置中的共用 AI 连接。机器人在游戏里的聊天也会进入 AIRI 的感知与规划流程。界面显示实际连接状态、生命、饱食度、坐标、玩家、聊天和动作开始/完成/失败记录。

AI 没有启用时，连接仍可用于观察和直接跟随操作，认知规划保持暂停。“恢复 AI”需要启用共用 AI 连接。

“暂停并停止”取消认知请求，清空 AIRI 控制动作队列并中止跟随和当前动作。“断开世界”、移除模块及退出宿主会关闭该模块的受管运行端。

角色资料在连接时取快照。切换工作台角色后，重新连接才绑定新的角色，避免运行中的旧请求串入新角色。

## 指定坐标建造

可以直接发送自然语言指令，例如“用背包的橡木木板，在 (3,65,3)、(4,65,3)、(5,65,3) 各放一块，完成后等待”。AI 使用 `placeBlockAt({type,x,y,z})` 执行，每次操作一个整数方块坐标。

运行端负责接近目标、选择精确匹配的材料、获取真实方块对象并确认最终方块种类。建造会解除自动跟随；已有同种方块视为完成，其他占位不会自动拆除。以箱子等可交互方块作为支撑时临时潜行，结束或失败后恢复原状态。目标区块未加载、缺少材料、没有支撑或服务端拒绝放置时会返回错误。

## 实现与接口

上游为 `moeru-ai/airi` 的 `integrations/minecraft`，固定 v0.15.1 / `89ec1e953f2e3b6f529d1f387d19bf5678ec6814`。该 Mineflayer 运行端正在向 Fabric 方案迁移，因此游戏引擎留在独立适配目录内。

| 接口 | 用途 |
|---|---|
| `GET /api/modules/mc-play/state` | 运行环境、连接快照和最近消息 |
| `PUT /api/modules/mc-play/connection` | 校验并保存六个连接字段 |
| `POST /api/modules/mc-play/connect` | 显式启动运行端并进服 |
| `POST /api/modules/mc-play/disconnect` | 停止运行端 |
| `POST /api/modules/mc-play/command` | `instruction / follow / come / pause / resume / chat` |
| `POST /api/modules/mc-play/open-auth` | 打开当前微软认证页 |
| `GET /api/modules/mc-play/skin` | 图片、生成和应用的公开状态 |
| `PUT /api/modules/mc-play/skin` | 校验并保存 PNG |
| `PATCH /api/modules/mc-play/skin` | 修改体型或可选 MineSkin Key |
| `GET /api/modules/mc-play/skin/image?revision=…` | 当前皮肤 PNG |
| `POST /api/modules/mc-play/skin/apply` | 异步生成并应用 |
| `POST /api/modules/mc-play/skin/reset` | 异步恢复默认，保留 PNG |

实例调用以上接口时添加 `/instances/<实例 ID>` 前缀。皮肤写操作返回完整 MC 状态；应用/恢复返回 HTTP 202，之后轮询 `state` 获取实际结果。

内部模型接口使用每次连接独立的随机令牌。令牌不进入命令行或前端状态，过期会话的请求与返回均会被拒绝。调试服务器、MCP 和 Viewer 不对外启动。

## 验证边界

`worker.mjs --self-test` 使用实际 AIRI 规划器和 `isolated-vm` 计算并检查结果。

`tools/qa-mc-play-protocol.mjs` 使用隔离的 Minecraft 协议服务与模型夹具，启动真正的 AIRI / Mineflayer 运行端，验证登录、位置、认知启动、模型请求、隔离规划、聊天工具的数据包、暂停与断开。

`tools/qa-mc-play.mjs` 在 Electron 中检查连接输入、保存与草稿、运行反馈、模型指令、跟随错误、暂停恢复、主题与小窗口。

这些验证不使用念念的真实世界、游戏账号或存档。真实世界中的长时陪玩、采集、建造、战斗，以及 Forge/Fabric 整合包协议兼容性仍需实际进服验证。实现不会把隔离服务验收显示为用户世界已经连接。
